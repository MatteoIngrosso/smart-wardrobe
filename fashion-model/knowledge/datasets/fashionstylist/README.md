# FashionStylist (men's subset)

`male-look_en.csv` and `male-label_en.csv` come unchanged from FashionStylist V1, English version:
https://github.com/recsys-benchmark/FashionStylist (licence: Creative Commons Attribution-NonCommercial 4.0,
see LICENSE.txt). "FashionStylist: An Expert Knowledge-enhanced Multimodal Dataset for Fashion Understanding",
FashionStylist authors, 2026.

Used here for a personal, non-commercial app: `python -m fashion dataset` turns 4 in 5 outfits into
`knowledge/learned/fashionstylist-men.json`; the rest are kept back for `python -m fashion bench`.
